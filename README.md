# Nguyen Viet Phuong — Computer Vision & Applied AI

Personal portfolio of an Artificial Intelligence student at FPT University, Can Tho.

**Website:** https://vphunggggg.github.io/

Five selected projects connect computer vision, language models and software: ThinkMed, SheetReason, ExamGuard, PigCounter and Chess Edition. The website includes responsive layouts, project filters, accessible detail dialogs and motion that respects reduced-motion preferences.

## Development

Built with HTML, CSS and browser JavaScript. No installation or build step is required. Serve this folder with any static HTTP server, for example `python -m http.server 8000`.

GitHub Pages publishes the root of the `main` branch. `.nojekyll` keeps the files as a plain static website. Changes to this branch update the live site.

See [DESIGN.md](DESIGN.md) for the visual system and [THIRD_PARTY.md](THIRD_PARTY.md) for asset and font provenance.
